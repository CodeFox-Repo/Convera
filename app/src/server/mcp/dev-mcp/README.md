# Dev MCP

Dev MCP is a development tool for the FoxyChat project, providing a Model Context Protocol (MCP) server that wraps and exposes various development tools for use in local and remote environments.

## Features
- Integrates multiple development tools for FoxyChat
- Supports both local and remote MCP server modes
- Easy tool registration and management
- Stdio transport for seamless client-server communication

Or integrate it as part of your FoxyChat development workflow.

## Directory Structure
- `server.ts`: Main entry for the Dev MCP server
- `tools/`: Collection of available development tools

## About
Dev MCP is designed to accelerate and streamline FoxyChat development by providing a unified interface for tool execution and management.
