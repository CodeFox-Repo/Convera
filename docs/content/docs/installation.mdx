# Installation

## Requirements

- **Node.js** 18 or later
- **PNPM** 8 or later
- **Python** 3.6 or later (for native modules)

## Steps

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/foxfoxy.git
   cd foxfoxy
   ```

2. Install dependencies for all packages:

   ```bash
   pnpm install
   ```

3. Launch the desktop client:

   ```bash
   pnpm start
   ```

On first run, FoxyChat will guide you through connecting your AI accounts.
