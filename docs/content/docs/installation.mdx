# Installation

This guide will walk you through the process of installing and setting up FoxyChat, an all-in-one chat application built with Electron.

## Installation Steps

### 1. Install Prerequisites

#### Node.js

Download and install Node.js from the [official website](https://nodejs.org/). We recommend using the LTS version.

#### PNPM

After installing Node.js, install PNPM globally by running:

```bash
npm install -g pnpm
```

Verify the installation:

```bash
pnpm --version
```

#### Python

Download and install Python 3 or higher from the [official website](https://www.python.org/downloads/).（highly recommend add to path for restart use)

Verify the installation:

```bash
python --version
# or on some systems
python3 --version
```

#### RobotJS Dependencies

FoxyChat uses RobotJS for system automation. Please ensure you have the following dependencies installed based on your operating system:

<Tabs items={["Windows", "macOS", "Linux"]}>
  <Tab>
    Install Visual Studio Build Tools 2022 or higher:

    1. Download the Visual Studio Build Tools from [Microsoft's website](https://visualstudio.microsoft.com/visual-cpp-build-tools/)

    2. During installation, select the "Desktop development with C++" workload

    3. Make sure the following components are checked under "Optional":
       - MSVC v143 - VS 2022 C++ x64/x86 build tools
       - Windows 11 SDK (10.0.22621.0)
       - C++ CMake tools for Windows

  </Tab>
  <Tab>macOS dependencies will be installed automatically during the installation process.</Tab>
  <Tab>
    For Linux, you'll need to install additional dependencies based on your distribution.
    
    For Ubuntu/Debian:
    ```bash 
    sudo apt-get install libxtst-dev libpng++-dev 
    ```
    
    For Fedora:
    ```bash
    sudo dnf install libXtst-devel libpng-devel 
    ```
  </Tab>
</Tabs>

### 2. Clone the Repository

```bash
git clone https://github.com/your-username/foxfoxy.git
cd foxfoxy
```

### 3. Install Dependencies

From the root directory, run:

```bash
pnpm install
```

After installation, you need to run the Electron setup script:

```bash
node node_modules/electron/install.js
```

<Callout type="info">
  This script ensures Electron is properly configured for your system. If you encounter any issues
  with Electron, running this script manually can often resolve them.
</Callout>

### 4. Configure Environment Variables

Navigate to the app directory:

```bash
cd app
```

Create a `.env` file based on the provided example:

```bash
cp .env.example .env
```

Edit the `.env` file and fill in the required credentials:

```
API_KEY=your_api_key_here
```
