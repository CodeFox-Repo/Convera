# FoxyChat Beta

FoxyChat is an AI-powered desktop application that uses the **Model Context Protocol (MCP)** to automate tasks and orchestrate tools. This brief documentation describes how to get started while more detailed guides are being prepared.

## Download MCP

The MCP server package provides the tooling needed for advanced integrations. Download the latest release from our repository and place the `mcp` binary somewhere in your `PATH`. Start it with:

```bash
mcp serve
```

FoxyChat will detect the running MCP server automatically.

## App Integration (coming soon)

A future release will add OAuth-based helpers so you can log into your favorite applications through MCP. These integrations will let FoxyChat control those apps directly from the desktop client.

## Built-In Tools

FoxyChat ships with several local tools to help you interact with your desktop environment. Additional tools can be installed from MCP packages.
