## About FoxyFox

FoxyFox is a modern, powerful desktop application that connects you to various AI models through a clean, intuitive interface. Built on Electron, it provides a seamless experience across platforms while maintaining the performance and features of a native application.

## Key Features

- **Multiple AI Providers**: Connect to OpenAI, OpenRouter, and other AI providers
- **Rich Chat Interface**: Support for markdown, code highlighting, and file attachments
- **Context Management**: Control what information is available to the AI
- **Workspace Organization**: Keep your projects and conversations organized
- **Customizable Experience**: Themes, shortcuts, and personalization options
- **Cross-Platform**: Works on Windows, macOS, and Linux
