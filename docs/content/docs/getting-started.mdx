# Getting Started

FoxyChat lets you chat with various AI providers through a single, streamlined desktop app. Follow these steps to get up and running:

1. [Install the prerequisites](/docs/installation).
2. Run `pnpm install` in the project root.
3. Start the desktop client with `pnpm start`.

Once running, you can open the settings panel to connect your preferred AI services.
