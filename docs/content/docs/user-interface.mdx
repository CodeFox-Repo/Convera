# User Interface

The FoxyChat window is divided into three main areas:

1. **Sidebar** – switch workspaces, open settings and choose an AI model.
2. **Chat List** – view recent conversations within the current workspace.
3. **Chat Area** – compose messages and read AI replies.

Use the gear icon in the sidebar to access configuration options. Keyboard shortcuts such as `Ctrl+N`/`Cmd+N` open a new chat quickly.
