# Configuration

After installation, you can fine‑tune FoxyChat from the **Settings** panel.

## Providers

Connect your favorite AI services by entering API keys for providers such as OpenAI or OpenRouter. You can manage models and set a default provider per workspace.

## General Options

- **Theme** – switch between light and dark mode.
- **Notifications** – toggle desktop notifications.
- **Startup** – choose whether FoxyChat launches when you log in.

## Config File

Advanced users can edit the configuration file directly. It is stored in your operating system's application data folder and looks like this:

```json
{
  "providers": {
    "openai": {
      "apiKey": "YOUR_KEY"
    }
  },
  "settings": {
    "theme": "system",
    "notifications": true
  }
}
```

Changes are applied the next time you restart the app.
